# Brickstorm: Software and Symbolic AI

**Team name:** Brickstorm  
**Course:** Foundations of CS & AI 2026  
**Selected module:** Software and Symbolic AI (Chapter 3: Software & Algorithms, Chapter 4: Symbolic AI)

## Purpose and Intended Learners

We teach Software and Symbolic AI to **beginners**, including students from non-technical majors, through three connected resources built from one shared Markdown source: a **Study Guide**, **PPT Slides** and **Video Tutorials**.
